# sillybus

You probably meant **[sillybos](https://pypi.org/project/sillybos/)**, and
this package installs it: `sillybus` is the misspelling of sillybos that is
easiest to make. There is nothing else in here,
and there never will be; it exists so that the name points at the right
place rather than at whatever someone else might put under it.

```bash
pip install sillybos
```

sillybos (say it *SIL-lee-boss*) decides, before any image library or PDF
renderer opens a file, whether it is one of the formats you meant to read,
within the limits you expect, and if not, why. The name is the Greek
σίλλυβος, Latin *sittybus*: the little parchment tag that hung from a
rolled scroll in an ancient library, so a reader could tell what a scroll
was without unrolling it.

The code and the documentation are at
[github.com/scattercode/sillybos](https://github.com/scattercode/sillybos).
